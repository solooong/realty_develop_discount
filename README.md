# Рассрочка·Дом — прототип портала подбора новостроек по субсидированным программам застройщиков

Интерактивный прототип (React + Vite + Tailwind CSS) по документации проекта
`realty_devel_discount`: User Flow (шаги 0–7), «База данных MVP», ТЗ №5
(управление базой и фильтрами главной через Django Admin), маппинг XML-фида
Яндекс.Недвижимости. **Бэкенда и реальных БД нет** — вся «база» живёт
in-memory + localStorage, но поведение повторяет финальную систему.

---

## Быстрый старт

```bash
npm install        # или: распаковали архив → сразу смотрите dist/
npm run build      # сборка в dist/
npm run dev        # дев-сервер с HMR
```

Готовый к показу статический бандл — папка `dist/`: её можно открыть с любого
хостинга, залить на любую статику или просто вложить в архив.

## Что внутри

### Портал (путь пользователя по ТЗ)
1. **Шаг 0** — геопромт «Показать квартиры рядом с вами?» (Да / Выбрать район)
2. **Шаг 1** — три целевые группы: Молодая семья / Инвестор / Индивидуальный покупатель
3. **Шаг 2** — слайдер бюджета 4–60 млн ₽ с авторасчётом допустимой цены (ПВ 15–20%)
4. **Шаг 3** — специализированные фильтры **зависят от ЦГ**: семейная и IT-ипотека,
   дети до 7, беременным, маткапитал, инфраструктура (семья); ROI / окупаемость /
   арендная ставка (инвестор); типы рассрочки и уникальные условия (индивидуал)
5. **Шаг 4** — выдача: эмблемы условий («0%», «Ключи до оплаты»…), цепочка цен
   «с ремонтом → базовая → по программе → выгода», избранное, сравнение
6. **Шаг 5** — карточка ЖК: калькулятор (ПВ/срок, мгновенный пересчёт, сравнение
   с ипотекой 21% по 4 банкам, удорожание % + фикс), конверсии **без регистрации**:
   просмотр, бронь, звонок, МАКС/WhatsApp, подписка на цену
7. **Шаг 6** — сравнение до 4 ЖК: переплата, итог, ипотека 21%, график выплат
8. **Шаг 7** — конверсия пишется в «CRM» (раздел «Заявки» админки)

### Админка (прототип Django Admin)
- Дашборд с **живой воронкой**: действия на портале реально двигают счётчики
- CRUD `DeveloperOffers` — все поля из раздела «База данных MVP»
- Фиды застройщиков: симуляция синхронизации XML + таблица маппинга тегов Яндекса
- Заявки `UserConversions` со статусами (новая / в работе / закрыта)
- **Главная и фильтры по ТЗ №5**: тексты и блоки фильтров (вкл/выкл, порядок)
  применяются на портале мгновенно
- AI-агент: сценарии, покрытие, журнал диалогов, роадмап

### AI-агент «Домовой»
- Подбор по свободной фразе: «двушка для семьи до 15 млн без процентов»
- Калькулятор в чате: «Рассчитай платёж: 12 млн, ПВ 20%, 24 мес»
- FAQ: маткапитал, trade-in, ключи до оплаты, удорожание, 214-ФЗ
- Передача диалога менеджеру → заявка в админке
- В прототипе — rule-based NLU, в релизе предполагается LLM

## Как заархивировать

```bash
# весь проект (исходники + сборка):
zip -r realty_devel_discount_prototype.zip . -x "node_modules/*" -x ".git/*"

# только готовый статический бандл для показа:
cd dist && zip -r ../realty_prototype_dist.zip . && cd ..
```

## Структура проекта

```
src/
  data/offers.ts       типы + seed-база (14 ЖК, DeveloperOffers по ТЗ) + FAQ
  lib/finance.ts       расчёты: рассрочка, удорожание, аннуитет, ROI, выгода
  lib/store.tsx        глобальный стор: сессия, фильтры, заявки, админ-настройки
  components/          UI-кит (SVG-иконки), карточка ЖК, AI-агент
  views/               Wizard, Results, OfferDetail, Compare, Admin
```

Данные в seed — вымышленные (демо для показа заказчикам), бренды застройщиков
реальные, цены ориентированы на рынок Москвы 2026 г.
